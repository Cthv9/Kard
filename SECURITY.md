# Security Policy

Questo repository contiene la vecchia PWA di Kard (dismessa) e le pagine
pubbliche dell'app Android (privacy, cancellazione account, segnalazioni).

## Segnalare una vulnerabilità

**Non aprire issue pubbliche.** Usa uno di questi canali privati:

- Modulo GitHub: **Security → Report a vulnerability** di questo repository
- Email: [Cthv9.dev@gmail.com](mailto:Cthv9.dev@gmail.com?subject=Sicurezza%20Kard), oggetto *"Sicurezza Kard"*

Tempi, ambito e versioni supportate: <https://cthv9.github.io/Kard/sicurezza.html>.
